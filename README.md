# claude-gui

Claude Code（Claude Agent SDK）と複数セッションで並行してやり取りするための macOS デスクトップアプリ（Electron）。

- 左: 選択中セッションのリポジトリのファイルツリー（ファイルをクリックすると入力欄に `@パス` を挿入）
- 右: タブ単位のチャット。タブごとに別の Claude セッション（CLI プロセス）が動く

## インストール

```sh
yarn install
yarn app:build   # release/mac-arm64/Claude GUI.app ができる
```

できた `Claude GUI.app` を `/Applications` にドラッグすれば Dock / Launchpad から起動できる。コードを変更したら `yarn app:build` し直して置き換える。

- 署名はアドホックのみ（自分の Mac で使う前提。配布はしない）
- 初回起動時、リポジトリを探すフォルダは `~/Documents/src`。メニュー「Claude GUI → リポジトリのフォルダを変更…」で変えられる
- 設定・タブ一覧は `~/Library/Application Support/Claude GUI/` に保存される
- Dock から起動すると PATH が最小限になるため、起動時にログインシェルの PATH を取り込んでから Claude を動かす（Bash や hooks から node / git などが使える）
- ウィンドウを閉じてもアプリは終了しない（実行中のセッションは続く）。終了は `⌘Q`

## 開発

| コマンド     | 内容                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| `yarn app`   | ビルドしてデスクトップアプリを起動（リポジトリのフォルダはこの親）          |
| `yarn dev`   | ブラウザで開発（http://127.0.0.1:5173 、サーバーは tsx watch で自動再起動） |
| `yarn start` | ブラウザ版をビルドして http://127.0.0.1:3939 で起動                         |
| `yarn lint`  | 型チェック＋prettier チェック                                               |

構成: `server/`（HTTP + WebSocket サーバー。Agent SDK でセッションを管理）、`web/`（React の画面）、`electron/`（アプリ本体。サーバーを内部で起動してウィンドウに表示）、`shared/`（両者で共有する型）。

デスクトップ版とブラウザ版は同じポート（`PORT`、既定 3939）を使うため同時には起動できない。

## 操作

| 操作                       | 方法                                                         |
| -------------------------- | ------------------------------------------------------------ |
| 送信                       | `⌘+Enter`（Enter は改行）                                    |
| 応答の中断                 | `Esc`（日本語の変換中は除く）                                |
| セッション名の変更         | タブをダブルクリック、またはチャット上部のタイトルをクリック |
| リポジトリの選択           | 左上のプルダウン（最初のメッセージを送るまで変更可）         |
| 過去のセッションを開く     | タブバー右の時計アイコン                                     |
| ターミナルで続きをやる     | チャット上部のコピーアイコン（`claude --resume` コマンド）   |
| ツール実行の許可・質問回答 | チャット下部に出るカードで操作                               |
| コマンドのコピー           | コードブロック右上の「コピー」、文中の `コード` はクリック   |
| 使用量の確認               | サイドバー下部（5時間枠・週間枠。更新ボタンで即時取得）      |

- セッション名は Claude が自動で付けたものを使い、手動で変更した場合はセッションファイルにも保存する（CLI の `/resume` にも反映される）
- 権限モードはタブごとに `default` / `acceptEdits` / `auto` / `plan` から選べる。新しいタブは開いているタブのモードを引き継ぐ（初期値は `auto`）
- `~/.claude/settings.json` などの設定・CLAUDE.md・hooks は CLI と同じく読み込まれる
- タブを閉じても Claude のセッション履歴は残る（履歴から開き直せる）
- 応答完了後 30 分操作がないタブは CLI プロセスを終了し、次の送信時に resume で再開する
- 使用量は CLI の `/usage` と同じデータ（SDK の実験的 API）。起動時・5分ごと・応答完了後に更新し、稼働中のセッションがなければ CLI を一時起動して取得する（会話はしないので利用枠は消費しない）

## セキュリティ

Claude にコマンドを実行させられるため、内部サーバーは `127.0.0.1` でのみ待ち受け、Host / Origin ヘッダーがこのアプリ自身の画面（`http://127.0.0.1:<PORT>` など。`yarn dev` のときだけ Vite の 5173 番も）以外のリクエスト・WebSocket は拒否する。DNS リバインディングや、ブラウザで開いた他サイト・localhost の別ポートで動く他のアプリからの操作を防ぐため。
